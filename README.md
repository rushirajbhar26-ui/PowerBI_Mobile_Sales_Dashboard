# 📱 Mobile Sales Dashboard | Power BI

An interactive **Mobile Sales Dashboard** created using **Microsoft Power BI** to analyze mobile sales performance and identify trends across different business dimensions.

The dashboard transforms sales data into an interactive and easy-to-understand visual report using KPI cards, charts, a map, tables, and slicers.

## 🎯 Project Objective

The main objective of this project is to analyze mobile sales data and create an interactive dashboard that provides a clear overview of sales performance.

The dashboard helps analyze:

- Overall sales performance
- Total quantity sold
- Number of transactions
- Average sales value
- Monthly sales trends
- City-wise sales performance
- Brand-wise sales and quantity
- Mobile model performance
- Customer ratings
- Payment method distribution
- Day-wise sales trends

---

## 🔍 Analysis Performed

### 📅 Monthly Analysis
Analyzed total quantity sold across different months to understand monthly sales patterns and trends.

### 🌍 City-wise Sales Analysis
Used a map visualization to analyze total sales across different cities in India.

### 🏷️ Brand-wise Analysis
Compared brands based on:

- Total Sales
- Total Quantity

### 📱 Mobile Model Analysis
Analyzed sales performance of different mobile models to compare their contribution to total sales.

### ⭐ Customer Ratings Analysis
Visualized customer ratings to understand the distribution of customer feedback.

### 💳 Payment Method Analysis
Analyzed sales and transactions across different payment methods, including:

- Credit Card
- Debit Card
- UPI
- Cash

### 📆 Day-wise Sales Analysis
Analyzed total sales across different days of the week to identify sales patterns.

---

## 🎛️ Interactive Filters

The dashboard includes interactive slicers that allow users to explore the data based on:

- **Month**
- **Mobile Model**
- **Payment Method**

These filters make it easier to analyze specific segments of the sales data.
